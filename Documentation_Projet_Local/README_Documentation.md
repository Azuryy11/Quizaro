# Documentation du projet Quizaro

Ce dossier local centralise les documents du projet en dehors du dépôt Git.

Derniere mise a jour: 01/05/2026

## Fichiers présents

- `Quizaro_Planning.odt` : planning du projet.
- `Quizaro_UML.odt` : éléments UML du projet.
- `Quizaro_MLD.png` : modèle logique de données.
- `Quizaro_Logo.avif` : logo du projet.
- `Quizaro_Logo2.png` : variante du logo.
- `db-erd.mmd` : schéma de base de données au format Mermaid.
- `README_Projet.md` : README du projet Symfony.
- `Technologies_utilisees.md` : synthèse des technologies utilisées.
- `Architecture_Projet.md` : vue d'ensemble de l'architecture technique.
- `Structure_Projet.md` : repères sur l'arborescence du projet.
- `Commandes_utiles.md` : commandes pratiques pour lancer et maintenir le projet.
- `Charte_Graphique.md` : charte visuelle (logo, couleurs, typographie, ambiance UI).
- `Design_System.md` : design system base sur les composants et tokens reels du code.

- `symfony-docker/Quizaro_Planning.pdf`
